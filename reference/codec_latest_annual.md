# CoDEC latest annual

CoDEC data is harmonized as the most recently available annual (or
annual average of monthly) values at the census tract 2020 geography.
The year represents the year this table was assembled and mainly used as
a placeholder to this object can be used with functions that take a
codec_tbl object (see
[`?as_codec_tbl`](http://geomarker.io/codec/reference/as_codec_tbl.md)).
See the description metadata for the actual latest years used for each
CoDEC table.

## Usage

``` r
codec_latest_annual
```

## Format

An object of class `codec_tbl` (inherits from `tbl_df`, `tbl`,
`data.frame`) with 226 rows and 66 columns.
